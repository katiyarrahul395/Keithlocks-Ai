The chat backend now uses OpenRouter. Set OPENROUTER_API_KEY in Netlify's environment variables. The key is used only by the serverless function and is never placed in the browser.

By default the function uses OpenRouter's openrouter/free router. You can optionally set OPENROUTER_MODEL in Netlify if you want to choose a specific model.
